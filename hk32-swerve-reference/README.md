# HK32 Swerve Reference Sketch

A standalone Arduino sketch retained as a reference for the HK32 swerve controller.

## Use

Open `hk32-swerve-reference.ino` in Arduino IDE and select the correct STM32/HK32-compatible board package, board, and upload method. Check the sketch for its pin mapping and serial wiring assumptions, then verify them against your hardware before uploading.
